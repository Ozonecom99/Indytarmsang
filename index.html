รายการเมนูอาหารทั้งหมด

0 รายการ
เมนูอาหาร หมวดหมู่ ราคา สถานะสินค้า จัดการ

คู่มือการนำโปรเจกต์ขึ้น GitHub และใช้งานจริง

วิธีอัปโหลดเว็บแอปพลิเคชันนี้ขึ้น GitHub และเปิดให้คนอื่นใช้งานผ่าน GitHub Pages ฟรีๆ

1

ดาวน์โหลดโค้ดเป็นไฟล์เดี่ยว (HTML)

คุณสามารถกดปุ่มด้านล่างเพื่อดาวน์โหลดซอร์สโค้ดหน้านี้ทั้งหมดบันทึกเป็นชื่อไฟล์ index.html ไว้ในคอมพิวเตอร์ของคุณ

2

สร้าง Repository บน GitHub

  • เข้าไปที่เว็บไซต์ github.com และเข้าสู่ระบบ
  • ที่มุมขวาบน กดปุ่ม + แล้วเลือก New repository
  • ตั้งชื่อ Repository เช่น restaurant-app
  • เลือกตั้งค่าเป็น Public
  • ติ๊กถูกที่ช่อง Add a README file
  • กดปุ่ม Create repository ด้านล่างสุด
3

อัปโหลดไฟล์ index.html ขึ้น GitHub

  • ในหน้า Repository ของคุณ ให้กดปุ่ม Add file > Upload files
  • ลากไฟล์ index.html ที่ดาวน์โหลดไว้ ไปวางในช่องอัปโหลด
  • กดปุ่มสีเขียว Commit changes เพื่อบันทึก
4

เปิดใช้งาน GitHub Pages (เพื่อให้เว็บไซต์ออนไลน์ฟรี)

  • ไปที่แท็บ Settings ด้านบนของ Repository
  • ที่เมนูด้านซ้าย ให้คลิกที่หัวข้อ Pages
  • ในส่วนของ Build and deployment > Branch ให้เปลี่ยนจาก None เป็น main (หรือ master) และเลือกโฟลเดอร์เป็น / (root)
  • กดปุ่ม Save
  • รอประมาณ 1-2 นาที เว็บไซต์ของคุณจะแสดงลิงก์ Public URL สามารถนำไปแชร์ให้ลูกค้าดูเมนูและเวลาเปิด-ปิดได้ทันทีครับ!
